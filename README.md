GOAL

The goal of this class project was to create a game similar to Arkanoid using the Visual Studio Console. 

How I resolved it

I developed a paddle-and-ball game and expanded on the initial concept by implementing a ranking system with save functionality. I also added a main menu with options for Play, Ranking, and Exit. Players control the paddle using the A and D keys, and can navigate back in the ranking menu using ESC. 

What I learned

I gained hands-on experience with game loops, save systems, and menu navigation logic. This project helped me strengthen my understanding of structuring games and going beyond core requirements to deliver a more complete experience.
